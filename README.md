## 🤖 Agentic Engineering

One of my main areas of exploration is **agentic software engineering**.

Rather than treating AI as simply a coding assistant, I'm interested in systems where multiple specialized agents can participate in a controlled engineering workflow.

A typical workflow I'm experimenting with looks like:

```text
Human
  │
  ▼
Task / Intent
  │
  ▼
Agent Orchestrator
  │
  ├── Research
  ├── Planning
  ├── Implementation
  ├── Code Review
  ├── Testing
  ├── Architecture Validation
  └── Documentation
          │
          ▼
      Verified Change
          │
          ▼
        Human
```

The important part isn't simply making agents autonomous.

It's making them:

* **observable**
* **constrained**
* **repeatable**
* **testable**
* **architecture-aware**
* **easy for humans to review**

This is also why I'm interested in **Model Context Protocol (MCP)** and tools that allow agents to discover project-specific knowledge instead of relying entirely on prompts.

## 🔬 Research Interests

I'm particularly interested in the future of software engineering when AI agents become active participants in development.

Areas I'm exploring include:

### Reliable Agentic Software Engineering

How can we evaluate whether an AI agent actually produces software that satisfies engineering requirements rather than merely generating code that appears correct?

### AI-Assisted Software Development

How can agents participate in:

* requirements analysis
* architecture
* implementation
* testing
* debugging
* code review
* documentation
* deployment

while keeping humans meaningfully involved?

### Trustworthy Generative AI

I'm interested in systems that make AI-generated decisions and changes more:

* verifiable
* explainable
* reproducible
* auditable
* constrained

### Human-Agent Collaboration

Rather than replacing developers, I’m interested in how humans and agents can work together through well-defined interfaces, tools, feedback loops, and governance.
